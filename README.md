# js-variables

This is a small practice file about JavaScript variables. Run it with node to see the output.

## What it shows

- `var`, `let`, and `const` and how they are different
- Changing a value stored in a `let` variable
- Basic data types: string, number, boolean, array, and object
- Changing the contents of a `const` array with `push`
- Using `typeof` to check the data type of a variable

## How to run

```
node script.js
```
